# 🤖 Stenku: The Magical Helper Robot for Businesses! 

Imagine you are running a busy toy store. Your friends keep texting you on WhatsApp:
* *"I want 20 blue lego bricks!"*
* *"Budi paid for his toy car!"*
* *"We only have 5 teddy bears left!"*

If you had to write all of this down in a big notebook by hand, your hands would get very tired, and you might lose some notes.

**Stenku is like a magical helper robot that does this work for you!**

---

## 🌟 How the Magic Works

This project is made of four cool parts that work together like a team:

### 1. 🖼️ The Shop Window (The Website)
This is what people see when they search for Stenku on the computer. It looks pretty, tells everyone what the helper robot can do, and has a **magical form** at the bottom where people can write messages to us.

### 2. 🧠 The Robot's Brain (The AI Agent)
When someone writes a message, the robot listens carefully. 
* If someone says: *"I bought 20 stickers,"* the robot doesn't just read it; it **understands** it!
* It takes the words and turns them into clean numbers and neat lists.

### 3. 📚 The Big Book of Secrets (The D1 Database)
This is the robot's notebook. Every time someone sends a message through the website form, the robot quickly writes down their Name, Email, and what they want inside this digital notebook so it is never lost.

### 4. 🔑 The Shopkeeper's Secret Office (The Admin Dashboard)
Only the boss (that's you!) has the key to this office. 
* You type in your secret name (`kennkurn`) and secret password (`admin123`) to unlock the door.
* Inside, there is a giant table showing every single note the helper robot has written down in **The Big Book of Secrets**!

---

## 🚀 How to Run the Magic at Home

If you want to open the shop on your own computer, you run a special command:
1. Open the command terminal (the black box where you talk to the computer).
2. Type: `npm run dev`
3. Press **Enter**! The computer will give you a link. Click it, and your website will appear!
